Photographs by John Margolies, Library of Congress, Prints & Photographs Division, John Margolies Roadside America Photograph Archive. The Library of Congress acquired the intellectual property rights and reports [no known copyright restrictions on these photographs](https://wwws.loc.gov/rr/print/res/723_marg.html).

| Photograph | Use |
| --- | --- |
| [1001 Nights ride, Ocean City, Maryland](https://www.loc.gov/item/2017712397/), 1985. LC-DIG-mrg-10311. | Cover, film gallery, exposure demo and reference match source. |
| [Twi-Lite Cinema Center, Great Falls, Montana](https://www.loc.gov/pictures/item/2017708008/), 1987. LC-DIG-mrg-05915. | Halation, bloom and grain demos. |
| [The Donut Hole, La Puente, California](https://www.loc.gov/pictures/item/2017702197/), 1991. LC-DIG-mrg-00081. | Reference match target. |

The scans were cropped and resized. The FIXER OFX/CUDA test host processed DaVinci Wide Gamut / Intermediate inputs. The README images convert Rec.709 Gamma 2.4 renders to sRGB and apply a uniform +0.75 EV gain in linear display light to all panels, including the source and reference. The gain is applied after rendering and does not change the plugin settings used in each comparison.

- **Film and exposure.** The gallery uses the datasheet profiles. The exposure example varies only film exposure on Vision3 250D with 2383 print.
- **Glow and grain.** The Twi-Lite crops use Vision3 500T with 2383 print. Halation is shown at 0.38 with radius 20, bloom at 0.28, and grain at amount 0.9 and size 2.
- **Reference match.** Film + match uses Vision3 250D with 2383 print. Both modes use match strength 1.0 and skin protection 0.5.
