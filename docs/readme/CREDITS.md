The FIXER OFX/CUDA test host processed DaVinci Wide Gamut / Intermediate inputs. The README images convert Rec.709 Gamma 2.4 renders to sRGB. The film gallery, GIF, glow, grain and reference match comparisons apply a uniform +0.75 EV gain in linear display light after rendering, including their source and reference panels.

- **Film profiles.** The gallery uses the datasheet profiles.
- **Glow and grain.** The Twi-Lite crops use Vision3 500T with 2383 print. Halation is shown at 0.38 with radius 20, bloom at 0.28, and grain at amount 0.9 and size 2.
- **Reference match.** Film + match uses Vision3 250D with 2383 print. Both modes use match strength 1.0 and skin protection 0.5.
